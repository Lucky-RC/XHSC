# XHSC

This repository contains XGBoost-based codes for Arctic and Antarctic sea ice type classification using Tianmu-1 GNSS-R observations.

The models distinguish First-Year Ice (FYI) and Multi-Year Ice (MYI) using preprocessed GNSS-R features.

Main features:
- LHCP Power (`S_LH`)
- Anisotropy (`rho_axis`)
- Peak Side Lobe Ratio (`R_peak_ratio`)

The repository includes separate classification experiments for the Arctic and Antarctic, together with model training, prediction, and accuracy assessment.
